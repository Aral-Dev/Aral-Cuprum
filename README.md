# ARAL CUPRUM

> **پنل سرورلس رایگان و متن‌باز VLESS + Trojan + Shadowsocks روی شبکهٔ کلادفلر — نسخهٔ ۱.۰.۰ «راکتور»**
> Free & open-source serverless tunnel panel for Cloudflare Workers & Pages.

[![Version](https://img.shields.io/badge/version-1.0.0-ff4d00.svg)](https://github.com/Aral-Dev/Aral-Cuprum)
[![License](https://img.shields.io/badge/license-OPEN-00ff9d.svg)](#-لایسنس)
[![Cloudflare](https://img.shields.io/badge/Cloudflare-Workers%20%26%20Pages-f38020.svg)](https://workers.cloudflare.com)

**Aral Cuprum** بازطراحی کامل نسل جدید پنل آرال است — همان هستهٔ اتصال و ساخت کانفیگ اثبات‌شده،
اما با یک طراحی تمام‌جدید («راکتور»): سایدبار مدیریتی، تم مشکی-آتشین با نئون کوپروم، تایپوگرافی
Orbitron، لایه‌های پس‌زمینهٔ رادار و اسکن‌لاین، و صحنهٔ پیکسل‌آرت تعاملی «قلهٔ آرال».

---

## ✦ نصب ۶۰ ثانیه‌ای (بدون ترمینال)

1. در کلادفلر یک **KV Namespace** بسازید (مثلاً `aral`).
2. یک Worker جدید با **Start with Hello World** بسازید و Deploy کنید.
3. **Edit code** → کل محتوای [`worker-single-file.js`](./worker-single-file.js) را جایگزین کنید → Deploy.
4. در تنظیمات ورکر: **Bindings → Add → KV namespace** → نام متغیر را دقیقاً `KV` بگذارید و فضای خود را انتخاب کنید.
5. آدرس ورکر را باز کنید؛ فرم انتخاب رمز مدیر بالا می‌آید و پنل کامل فعال می‌شود.

> برای Cloudflare Pages: محتوای پوشهٔ `dist/` (یا فایل `aral-cuprum-pages.zip`) را آپلود کنید — همان ورکر با همان KV کار می‌کند.

## ✦ قابلیت‌ها

| هسته | جزئیات |
| --- | --- |
| پروتکل‌ها | VLESS + Trojan + Shadowsocks (AEAD) روی WebSocket |
| چندکاربره | KV-backed، تا ۲۰۰ مشترک، سهمیهٔ GB / روز / تعداد اتصال / دستگاه همزمان |
| ضد فیلتر | Fragment (1-1 / tlshello / ملایم)، UDP Noise، ECH، Pattern (fm/cs/mask) |
| IP تمیز | اسکنر مرورگر، رنج‌های رسمی CF، مخازن دادهٔ جامعه، چرخش خودکار |
| لوکیشن | خروجی چندکشوری با پروکسی زنجیره‌ای + تعویض خودکار لوکیشن خراب |
| تلگرام | Web Proxy رسمی (`tg://webproxy`) + بات مدیریتی با وبهوک خودکار و ارسال QR |
| DNS | Private DoH رمزنگاری‌شده روی همان ورکر (`/dns-query/<token>`) |
| مسیریابی | Bypass ایران/چین/روسیه/LAN، مسدودسازی تبلیغات/محتوای بزرگسال، فهرست‌های سفارشی |
| پنل | تلگراف زندهٔ سرعت/پینگ، مشاور هوشمند ISP، پشتیبان JSON، خودبروزرسان از گیت‌هاب، PWA |

## ✦ طراحی «راکتور»

- **زبان بصری Aral CF**: مشکیِ راکتور `#070707`، نارنجیِ آتش `#ff4d00`، سبزِ کوپروم `#00ff9d`
- گوشه‌های بریده (clip-path)، عنوان‌های Glitch، بیم رادار، اسکن‌لاین و گرید متحرک
- چیدمان مدیریتی با **سایدبار چسبان** + نوار وضعیت راکتور؛ در موبایل به ریل افقی جمع می‌شود
- فونت: Vazirmatn (فارسی) · JetBrains Mono · Orbitron (نمایشی) — همه سلف‌هاست و ساب‌ست‌شده
- تم روشن/تارک و زبان فارسی/انگلیسی با یک کلیک
- صحنهٔ **پیکسل‌آرت تعاملی کوه آرال** در صفحهٔ ورود و کارت مشترک (جایگزین تصویر قدیمی)

## ✦ رفع باگ‌های مهم این نسخه (نسبت به Aral Ultra 4.2)

1. **پرش فرم بات تلگرام**: پول ۱۰ ثانیه‌ای دیگر فیلد توکن/آیدی را هنگام تایپ پاک نمی‌کند (گارد `setVal`).
2. دکمهٔ «مشترک جدید» در پیشخوان به‌خاطر تابع حذف‌شده خطا می‌داد — اکنون مستقیم مودال را باز می‌کند.
3. کلید Escape حالا **همهٔ** مودال‌ها را می‌بندد (قبلاً فقط دو مودال).
4. لرزش/پرش صفحه در رفرش خودکار دفتر مشترکین با امضای داده + بازیابی اسکرول رفع شد.
5. چشمک QR در رفرش‌های پس‌زمینه با کش طراحی حذف شد.
6. آیکون سطل زبالهٔ گمشده در مودال توکن کلادفلر اضافه شد.
7. هندلرهای تکراری دکمه‌های ساخت UUID/رمز پاک‌سازی شدند.

## ✦ ساخت از سورس

```bash
npm install
npm run build     # → worker-single-file.js + dist/ + panel-preview.html
npm test          # مجموعهٔ تست E2E (workerd + Playwright)
```

ساخت کاملاً آفلاین است؛ فونت‌ها با `pyftsubset` ساب‌ست می‌شوند و خروجی با ممیزی ۵۲ کلیدواژه‌ای
(بدون هرگونه امضای متنی پروتکل‌ها در باندل نهایی) بررسی می‌شود.

## ✦ ساختار

```
├── worker-single-file.js   ← خروجی نهایی برای Paste در داشبورد کلادفلر
├── dist/                   ← نسخهٔ Cloudflare Pages (index.html + _worker.js)
├── src/
│   ├── worker.js           ← مسیریاب HTTP/API
│   ├── protocols.js        ← موتور VLESS/Trojan/SS + DoH + ProxyIP/NAT64
│   ├── sub.js              ← تولید اشتراک + صفحهٔ مشترک (Press Pass)
│   ├── storage.js          ← لایهٔ KV و وضعیت
│   ├── tgbot.js/tgproxy.js ← بات تلگرام و Web Proxy
│   └── ui/                 ← پنل (index.html + style.css + app.js)
├── data/                   ← مخازن IP تمیز / پروکسی / لوکیشن
└── assets/aral-mountain.html ← صحنهٔ پیکسل‌آرت کوه آرال
```
